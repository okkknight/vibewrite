# TASK_20260411_025.md

## 本轮目标
本轮只完成：把当前客户端里混在一起的 AI 契约层抽出来，形成可被后端 AI 网关复用的共享协议层。

---

## 本轮背景

- V3 的 roadmap 已经把 Phase 0 标成已完成，后续 task 只需要按冻结后的边界往前拆。
- 当前仓库里还没有后端工程骨架，只有 macOS 客户端和共享代码。
- 现阶段最小、最稳妥的第一步不是搭后端服务，而是先把共享 AI contract 单独抽出来，避免后续后端和客户端继续共享一坨实现代码。
- 共享契约目前集中在 `Sources/VibeWriteApp/Shared/AI/WritingAIModels.swift`，其中既有协议和 DTO，也有 decoder、apply helper、stream/generate 默认实现等实现性逻辑。
- 这一步必须保持现有客户端行为不变，不能顺手改 prompt、改 provider、改流式体验，不能把 backend 技术栈提前定死。
- 其他 V3 文档继续作为 coder 的项目背景资料使用，task 本身只负责这一个最小切片。

## 本轮要做

- 把 `WritingAIModels.swift` 里的纯契约类型抽出来，单独形成一个共享契约文件
- 保持这些契约类型的字段、枚举 case、编码方式和现有语义不变
- 让后续 Phase 1 的后端 AI 网关可以直接复用这套共享契约
- 保持现有客户端、测试和流式行为不变

---

## 本轮不要做
- 不做后端服务搭建
- 不做 backend 语言或框架选型
- 不做 provider 接入
- 不改 prompt 逻辑
- 不改客户端行为
- 不改流式输出语义
- 不改本地编辑、保存、另存为、最近打开逻辑
- 不改 `project.prompt` 的语义
- 不引入新的 backend target
