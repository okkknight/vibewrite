# TASK_20260402_022.md

## 本轮目标
本轮只完成一件事：把首页入口、状态语义、响应式切换和最终产品一致性全部收口，完成严格对齐后的最后一轮整合。

这轮不是新功能开发，而是产品语义和运行状态的最终对齐：

- 首页的直接起稿和最近会话必须严格按文档表达
- 起稿中 / 正文协作中的状态语义必须清晰分层
- 宽屏和窄屏的侧栏呈现方式必须一致遵守文档
- 旧的讨论式语义和模板式误导都不能再出现

如果前四个任务做对了，这一轮负责把整套产品系统整合成一个严格一致的 V2。

## 本轮要做

- 严格对齐首页入口
  - 直接起稿必须是首页主入口
  - 最近会话必须是首页回流入口
  - 不允许在首页继续引入别的主入口
  - 不允许把“新建写作”做成另一个含糊的主路径

- 严格分层状态语义
  - `起稿中` 必须是明确阶段
  - `正文协作中` 必须是后续阶段
  - 不允许把两个阶段压成一个标签
  - 不允许再回到旧的讨论式语义

- 收口响应式策略
  - 宽屏时：正文中心 + 左 AI 侧栏 + 右历史 / 版本侧栏
  - 窄屏时：侧栏转抽屉 / overlay
  - 正文始终优先
  - 不允许因为布局变化破坏辅助层语义

- 最终清除旧语义
  - 旧的“讨论起稿中”表达必须继续保持清零
  - 不能再出现看起来像模板、像演示、像示例数据的误导内容
  - 主页和会话页都必须像真实产品，而不是 demo

- 做最后的整合与验收
  - 把前四个任务整合成一个一致的 V2
  - 补齐最后的测试
  - 在真实窗口里核对产品一致性

---

## 本轮不要做

- 不做新的 UI 结构重构
- 不做 AI 侧栏再设计
- 不做历史 / 版本再设计
- 不做 composer 再设计
- 不做 patch / streaming 语义修改
- 不做新的产品入口
- 不把首页做成导览页
- 不把阶段语义再压缩回一个标签
