# TASK_20260402_020.md

## 本轮目标
本轮只完成一件事：把历史 / 版本区域严格做成文档定义的独立抽屉或侧栏，不再退化为正文下方的普通按钮组。

这轮只负责历史 / 版本，不负责 AI，不负责 composer，不负责状态语义。

要做到的是：

- 展示最近会话
- 展示版本回退
- 展示 patch 历史
- 展示前后对比
- 展示重试最后一次修改

并且整体语义要保持“辅助回看”，不是“版本管理后台”。

## 本轮要做

- 把历史 / 版本做成独立抽屉或侧栏
  - 它必须是单独结构，而不是正文下方一行按钮
  - 它必须默认弱化或收起
  - 它必须能从顶部栏或侧边栏开关进入

- 组织历史内容
  - 最近会话列表
  - 当前项目的线性 patch 历史
  - 版本回退记录
  - 当前 revision 摘要
  - 前后对比入口

- 保持历史语义线性
  - 允许 undo / retry / compare
  - 不允许引入版本树、分支树、复杂 DAG
  - 不允许把历史做成项目管理器

- 收敛比较面板
  - compare 应该是显式动作
  - 不能在每次成功操作后自动强打扰
  - 比较面板应属于历史 / 版本语境，而不是悬浮在正文上抢戏

- 延续 task018 的白纸视觉
  - 历史区也必须是轻、薄、纸感
  - 不允许把历史做成深色数据看板
  - 不允许大卡片堆叠
