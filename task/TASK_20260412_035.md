# TASK_20260412_035.md

## 本轮要做

- 在 `Backend/` 里新增一个内存版 secret config store
- 这份 store 要同时管理：
  - `provider API key`
  - `admin 登录凭证`
- `POST /v3/admin/login` 必须改为读取这份 secret config store，而不是继续只读环境变量
- 这份 store 先做内存态即可，重启后回到环境变量 seed 值可以接受
- `GET /v3/admin/secrets` 必须受现有后台 session cookie 保护
- `GET /v3/admin/secrets` 返回的是脱敏后的当前配置状态，不返回 raw secret value
- `GET /v3/admin/secrets` 的固定字段是：
  - `providerApiKeyConfigured`
  - `adminUsername`
  - `adminPasswordConfigured`
  - `updatedAt`
- `PUT /v3/admin/secrets` 必须受现有后台 session cookie 保护
- `PUT /v3/admin/secrets` 接受的字段固定为：
  - `providerApiKey`
  - `adminUsername`
  - `adminPassword`
- `PUT /v3/admin/secrets` 支持按字段单独更新；未传入的字段保持原值不变
- 更新 `adminUsername` / `adminPassword` 后，后续登录必须立即使用新值
- 已有 session 在本轮内可以继续保持有效，直到显式 logout
- 这一步的初始值必须从现有环境变量 seed：
  - `MINIMAX_API_KEY`
  - `ADMIN_USERNAME`
  - `ADMIN_PASSWORD`
- 不要把 raw secret 写进日志、响应、测试失败信息或 debug 输出
- 补最小测试，覆盖：
  - 初始 seed 能正常登录
  - `GET /v3/admin/secrets` 返回脱敏后的 snapshot
  - `PUT /v3/admin/secrets` 可以更新 provider API key
  - `PUT /v3/admin/secrets` 可以更新 admin 登录凭证
  - 更新 admin 登录凭证后，新凭证可以登录、旧凭证不能登录
  - 现有后台 session / request query 行为不回退
