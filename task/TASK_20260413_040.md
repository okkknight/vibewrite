# TASK_20260413_040.md

## 本轮目标
本轮只完成：把现有后端管理 API 做成一个可以直接在浏览器打开的单人管理页。页面由 `Backend/` 直接服务，不引入新前端框架，默认入口是 `GET /v3/admin`。未登录时显示登录表单，登录后显示单页 dashboard，能直接查看和操作请求、密钥、AI system prompt、限额和设备。

---

## 本轮背景

- `task/TASK_20260412_034.md` 已经把后台登录 / 登出和 `GET /v3/admin/requests` 跑通了。
- `task/TASK_20260412_035.md` 已经把 provider API key 和 admin 凭证收进同一份 secret config store，并支持 `GET/PUT /v3/admin/secrets`。
- `task/TASK_20260412_036.md` 已经把当前 AI system prompt 配置收进同一份 config store，并支持 `GET/PUT /v3/admin/system-prompt`。
- `task/TASK_20260412_039.md` 已经把后台总览、quota 和 device 管理 API 跑通了。
- 现在仓库里没有独立的 web 前端骨架，也没有 Leaf / React / Next.js / Vue 之类的 admin UI 承载层。
- `docs/V3/ADMIN3.0.md` 已经定义了单人管理页要看的内容，这一轮就是把它变成可访问的页面，不再继续补后台 JSON API。

---

## 本轮要做

- 在 `Backend/` 里新增一个浏览器可访问的 admin 页面入口，默认路由为 `GET /v3/admin`
- 未登录时显示单人管理员登录表单
- 已登录时显示一个单页 dashboard，至少包含：
  - 总览
  - 请求列表
  - 密钥
  - AI system prompt
  - quota
  - devices
- dashboard 页面直接调用当前已有的后台 API：
  - `POST /v3/admin/login`
  - `POST /v3/admin/logout`
  - `GET /v3/admin/requests`
  - `GET /v3/admin/overview`
  - `GET /v3/admin/quota`
  - `PUT /v3/admin/quota`
  - `GET /v3/admin/devices`
  - `POST /v3/admin/devices/{installationId}/block`
  - `POST /v3/admin/devices/{installationId}/unblock`
  - `GET /v3/admin/secrets`
  - `PUT /v3/admin/secrets`
  - `GET /v3/admin/system-prompt`
  - `PUT /v3/admin/system-prompt`
- 页面交互只需要满足单人运维用途，不做复杂路由、不做多页面后台、不做复杂图表
- 保持 session cookie 认证逻辑不变，页面只是在现有 session 上增加浏览器视图

---

## 本轮不要做

- 不做新的前端框架
- 不做独立 web 站点
- 不做 React / Vue / Next.js / Svelte
- 不做数据库
- 不做 Redis
- 不做账号体系
- 不做 RBAC
- 不做多模型
- 不做 prompt 多版本管理
- 不做复杂图表
- 不做审批流
- 不做多页后台
- 不做正文原文展示

## 本轮主流程

1. 先阅读 `docs/V3/PRD3.0.md`、`docs/V3/IA3.0.md`、`docs/V3/ROADMAP3.0.md`、`docs/V3/API3.0.md`、`docs/V3/ADMIN3.0.md`、`docs/V3/BACKEND3.0.md`、`docs/V3/DATA3.0.md`、`docs/V3/DEPLOY3.0.md`、`docs/V3/MIGRATION3.0.md`、`PROJECT_CONTEXT.md`，确认后台页面是现有管理 API 的浏览器承载层，而不是新的产品线。
2. 在 backend 里实现一个 `text/html` 的 admin 页面入口，未登录时渲染登录表单，登录后渲染 dashboard 壳子。
3. 用最小量的 vanilla JS 把页面接到现有 admin API 上，确保总览、请求、密钥、system prompt、quota、devices 都能在页面里查看和提交。
4. 更新测试，覆盖：
   - `GET /v3/admin` 未登录时返回登录表单
   - `GET /v3/admin` 登录后返回 dashboard
   - 页面能调到现有 admin API
   - logout 能回到登录态
