## 本轮要做

- 重做会话页的视觉骨架
  - 宽屏下必须是**左边栏 + 中央正文 + 右边栏**
  - 边栏必须看起来像边栏，不是正文区里的折叠 section
  - 中央正文必须始终最重要、最清楚
  - 辅助层要服从正文，不许喧宾夺主

- 真正实现左右边栏
  - 收起态要像 folded rail，不是普通窄卡片
  - 展开态要像明确的边栏，不是卡片加宽
  - 左右边栏的视觉语义要稳定一致
  - 不允许仅靠 `width`、`opacity`、`padding` 的小修小补冒充重构

- 做窄屏 drawer 语义
  - 窄屏时左右边栏必须切换为 overlay / drawer
  - drawer 要有清晰的遮罩和关闭语义
  - 不允许窄屏下继续沿用桌面列宽逻辑

- 提升页面可读性
  - 不能再让页面看起来白茫茫一片
  - 正文、标题、说明、按钮必须有足够对比度
  - 辅助层文字不能再“漂”
  - 所有重要文案在真窗口中必须一眼可读

- 保留已正确的产品语义
  - 主页仍然只能保留直接起稿和最近会话
  - `起稿中` 与 `正文协作中` 仍然必须分层
  - composer 仍然必须是独立底部协作入口
  - patch / streaming 语义不要被这轮破坏

- 做视觉级最终验收
  - 要在真窗口里看
  - 要和 Codex 参考截图对照看
  - 只看单测不算完成
